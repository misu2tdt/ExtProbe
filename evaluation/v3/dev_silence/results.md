# Development set: how many malicious-labeled runs are silent for the network detectors

Generated by `evaluation/v3/dev_silence/count_silence.py`. Population: 278 runs of the development set labeled malicious by the public datasets (`label_verified = malicious` in `evaluation/v3/labels/labels_tiers.csv`; see the label terminology in `evaluation/README.md`) whose run completed. Counts only; Wilson 95% intervals. The traces are not in this repository.

Definitions: *extension-initiated request* = an item of `score_v3.ext_requests(events)` (service-worker requests recorded by the CDP session, plus page requests whose outermost caller is extension code). *Install-time tab* = an extension-opened tab reported by `score_v3` (signal `unsolicited_tab`). *Uninstall URL* = a recorded `runtime.setUninstallURL` call.

| measure | runs |
|---|---|
| no extension-initiated request at all | 151 / 278 = 54.3% (48.4%-60.1%) |
| an install-time tab | 178 / 278 = 64.0% (58.2%-69.4%) |
| an uninstall URL | 206 / 278 = 74.1% (68.6%-78.9%) |
| an install-time tab or an uninstall URL | 219 / 278 = 78.8% (73.6%-83.2%) |
| **both**: no extension-initiated request **and** (an install-time tab or an uninstall URL) | 123 / 278 = 44.2% (38.5%-50.1%) |

Reading: about half of these runs show no extension-initiated request, and most show an install-time tab or an uninstall URL, which the network detectors do not look at (an install or uninstall page is common in benign extensions too, see `evaluation/v3/audit/report.md`).
