# Reproducing (temporary)

Full instructions are written in the next step. What works now, without Docker or recorded traces:

```bash
python -m pytest -q
python -m extprobe verify-freeze
python evaluation/v2/check_paper_numbers.py --precomputed
```

The paper's v2 numbers come from four precomputed result files (`evaluation/v2/precomputed/`). Re-deriving them from the 354
recorded traces needs the trace archive (release asset) in `data/v2_results/`; `check_paper_numbers.py` without `--precomputed`
then also checks that `summary.csv` is regenerated byte-identically ("requires Zenodo traces"). The manual verdicts that name benign
extensions are kept out of the repository (`data/verdicts_local.json`, available on request).
